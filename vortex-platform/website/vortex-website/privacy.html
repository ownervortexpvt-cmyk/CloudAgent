Privacy Policy

VORTEX is built to be useful without harvesting your data. This policy explains, in plain language, what this website does and does not do with information.

Last updated: October 2026 · Applies to this website and all pages under it.

1. The short version

This is a static website. It has no user accounts, no sign-up forms and no comment sections. We do not ask you to register, and we do not collect personal information through this site itself. Anything you download or open here is served from the same public files that make up the site.

2. Information this site does not collect

Because the site is fully static, the following are simply not part of how it works:

  • No registration data — there are no accounts to create.
  • No form submissions stored on any server by this site.
  • No sales, payments or billing — nothing here requests financial information.
  • No hidden tracking profiles built by this site's own code.

3. Information stored in your browser (localStorage)

To make the site convenient, a few small preferences are stored in your own browser using localStorage: which app version you last downloaded (so we can show you an "Update version available" message), dismissed announcements, and — only if you are the site administrator — your admin settings and password hash. This information stays on your device. It is not transmitted anywhere by this site, and clearing your browser data removes it completely.

4. Downloads and external links

App files (APK, EXE) and web apps published on this site are provided by the VORTEX team through the links shown on each app page. If a link points to an external address, its content and any data handling on that destination are governed by that destination's own terms and policies — this policy covers only this website. We recommend downloading VORTEX software only from the links published here.

5. Hosting and technical logs

This site is hosted as static files (for example, on GitHub Pages). Like virtually all web hosts, the hosting provider may keep standard technical access logs (such as IP address, browser type and requested page) for security and operational reasons. Those logs are under the control of the hosting provider, not of this site's code, and this website's own scripts do not read or process them.

6. Children's privacy

The site does not knowingly collect any personal information from anyone, including children, because it has no mechanisms for doing so. It is a simple download and information hub suitable for a general audience.

7. Changes to this policy

If the way this site works ever changes in a way that affects this policy, the policy will be updated on this page with a new "last updated" date. Significant changes may also be announced on the site's announcement strip.

8. Contact

If you have questions about this policy, use the Contact page. The contact form opens your own email application, so nothing you type is stored on this site — the message is sent entirely from your email account.
