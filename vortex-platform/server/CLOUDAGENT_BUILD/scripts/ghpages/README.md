# ⚡ CloudAgent — AI Multi-Agent App Builder

**Public web release (GitHub Pages):** https://mdhonabali02.github.io/cloudagent-web/

CloudAgent is an AI app-builder SaaS where one instruction deploys a coordinated
swarm of up to 1,000 AI agents that plans, codes, reviews and ships real
software — with a real Linux terminal, GitHub two-way sync, APK / .exe exports,
template marketplace, live collaboration, custom domains and UPI payments via
Razorpay.
